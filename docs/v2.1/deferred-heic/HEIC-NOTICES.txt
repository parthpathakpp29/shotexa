HEIC decoder notices for Shotexa V2.1

Shotexa's HEIC converter uses heic-to 1.6.6 by Hopper Gee, which embeds
libheif 1.23.6 by Struktur AG, Dirk Farin and contributors. The libheif
Emscripten build uses libde265 1.0.16 by Struktur AG, Dirk Farin and
contributors for HEVC decoding. These components are covered by the GNU

  https://github.com/strukturag/libde265/tree/v1.0.16

The heic-to package's generated CSP decoder identifies libheif 1.23.6,
USE_UNSAFE_EVAL=0 and LIBDE265_VERSION=1.0.16. Its published development
instructions use USE_WASM=0. The distributed browser code is compiled
JavaScript; there is no separately served libheif WASM file in this build.

These notices and source pointers do not themselves supply a verified way to
recombine or relink Shotexa with a modified decoder. The HEIC-enabled build
remains subject to a separate release review of that requirement.
